# Performance Methodology

No performance claims are made until measured.

Every benchmark entry must document:

- Workload
- Hardware
- Software version / git commit
- Dataset or fixture
- Warmup procedure
- Sample count
- Measurement method
- Reported statistics: p50, p95, p99, throughput/goodput where applicable
- Known confounders

Benchmark name:
