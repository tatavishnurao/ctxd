# Engineering handbook (excerpt)

Fictional sample content for the ctxd dashboard demo.

## On-call

Each engineer joins the on-call rotation after their first two months. A shift lasts one week. The on-call engineer answers pages within 15 minutes and may hand a page to a secondary if they are already handling an incident.

## Code review

Every change needs one approving review before merge. Reviewers check correctness first, then tests, then readability. Large changes are split into smaller pull requests.

## Deploys

Production deploys run from the main branch through the deploy tool. Avoid deploying on Friday afternoons. Every deploy can be rolled back with one command.

## Time off

Book time off in the team calendar at least two weeks ahead and arrange on-call swaps yourself.
